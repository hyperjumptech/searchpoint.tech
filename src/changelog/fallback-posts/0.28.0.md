## 🚀 Improvements

- **Image Tagging**: You can now attach custom tags to images and search through images by their associated tags.
- **Enhanced Authentication**: Improved error reporting and visual status feedback during the login and SSO workflows.
- **OneDrive Shared File Access**: Enhanced file handling for shared OneDrive files, enabling direct "Open File" and "Open Folder" actions even for non-owned items.
- **Desktop Usage Statistics**: Introduced local usage statistics to track search productivity and indexed document metrics.
- **Dedicated Source Management**: Added a dedicated "Add Source" action row while retaining the quick header action.

## 🔧 Fixes

- Optimized background connection pooling for OneDrive, releasing unused sockets upon sync completion.
- Updated WhatsApp and OneDrive connector button styles on onboarding and source overview pages.
