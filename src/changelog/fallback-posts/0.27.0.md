## 🚀 Improvements

- **High-Accuracy OCR Engine**: Powered by Windows WinRT Media.Ocr, text recognition on image files and diagrams is now significantly more accurate.
- **AI Renamer for Images**: AI renamer now inspects visual contents and OCR extracts of images to propose meaningful names.
- **Resilient Model Downloads**: Handled network timeout errors (HTTP 408) automatically with exponential backoff during local LLM model provisioning.
- **Quick Look Previews**: Supported fast previewing of cloud-stored and SharePoint images directly from the search result list.

## 🔧 Fixes

- Fixed a UI layout shift that occurred during rapid search query typing.
- Corrected path normalization for Windows folder names with trailing whitespace.
- Restored and persisted the last window size and position across application restarts.
