SearchPoint 0.29.0 is now available. This release brings deep architectural improvements to local search intelligence, responsive UI layouts for varying monitor sizes, and powerful AI renaming rule customization.

## On-Device Concept Engine

SearchPoint now runs an on-device concept engine directly behind smart search. Rather than relying on simple keyword matching or shipping confidential file data to external cloud APIs, the concept engine builds a semantic relationship graph locally on your device. It understands synonyms, conceptual themes, and cross-document references in real time.

When you index new repositories or documents, the engine maps conceptual clusters in the background without hogging CPU or battery resources.

## Responsive Navigation & File Inspection

We have redesigned the "Open Folder" and "Open File" components to seamlessly adapt across diverse screen sizes and display densities. Whether you are using a compact laptop screen or an ultra-wide desktop monitor, search results and breadcrumbs now scale smoothly without truncating critical paths.

## Custom AI Renamer Rules

You can now design and fine-tune custom naming conventions for automated file renaming within Settings. Specify tokens, dates, and domain-specific tags that the AI renamer will apply across target directories.

## 🔧 Improvements & Fixes

- **Real-App Testing**: Ported E2E test framework from mock browser environments to real application runtime.
- **Favorites Sync**: Resolved file renaming synchronization issues with favorites and custom tags.
- **Crash Prevention**: Fixed a rare application crash during authentication setup caused by an early database index creation.
- **Deep Links**: Updated deep-link auth callback to handle state parameters reliably across external authentication redirects.
- **WhatsApp Indexing**: Scanned and indexed WhatsApp files per-document rather than per-chat session, with accurate sender labeling.
